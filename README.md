# 监考规划 · Web / PWA

学校教务人员使用的监考工作量计算器。纯 HTML、CSS、JavaScript，无后端、运行依赖或第三方 CDN。

## 使用

填写考试规模及人员类别，结果实时更新。各类人数互不重复，普通教师均摊剩余工作量；最低监考场数是硬约束，不可满足时显示调整提示。总需求以“监考人次”计，人员明细以“人”计。

- **刷新即重置**：没有保存、导入、导出、草稿或历史。输入和设置只在当前页面有效，浏览器历史返回也重置。
- **浅色 / 深色**：首次显示跟随系统，支持本次页面内手动切换；不提供其他配色。
- **计算过程**：默认隐藏，在“设置”中开启。
- **示例与重置**：可以填入原案例；替换已填写内容前会确认。
- **复制与分享**：仅针对当前有效结果。自动复制不可用时提供可手动选择的文字；系统分享只在支持的浏览器显示。
- **离线与安装**：首次在线加载并缓存完成后可离线计算；安装入口依浏览器而定。缓存只包含程序文件，离线刷新同样重置。

原示例：18 个考场、3 场、每考场 2 人、总教职工 69 人；班主任 18 人各 1 场，不参与 11 人，其他固定 1 场 4 人，普通教师最低 2 场。结果为 **108 人次**、实际参与 **58 人**；其他教师中 **22 人监考 2 场，14 人监考 3 场**。

工具只规划工作量，不生成具名监考表。所有教师按可参加任意场次处理，个人时间冲突需另行检查。

## 运行、验证和发布

在此目录执行（Node.js 20+）：

```powershell
node scripts/serve.mjs
node --test tests/*.test.mjs
node scripts/build.mjs
```

本地预览：`http://127.0.0.1:4173/`。发布目录：`dist/`。不要直接双击 HTML 文件。

完整说明见 [DEPLOYMENT.md](DEPLOYMENT.md)，已执行的检查见 [VERIFICATION.md](VERIFICATION.md)。

## 维护

- `src/calculator.js`：从 Android domain 移植的纯计算、校验及结果文本，BigInt 保证整数精度。
- `src/app.js`、`index.html`、`styles.css`：无框架界面、内存状态、复制分享及安装交互。
- `sw.js`、`manifest.webmanifest`、`icons/`：离线程序资源、安装信息与复用原生图标。
- `scripts/build.mjs`：按白名单生成发布目录，资源内容变化自动生成新的缓存版本。
- `scripts/serve.mjs`：只暴露应用运行文件的本地预览服务。
- `tests/`：计算与 PWA 行为回归测试。

修改后重新运行测试和构建，部署整个 `dist/`。后台下载新版不会刷新正在计算的页面；用户主动更新时才重置。
